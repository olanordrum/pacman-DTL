# Pac-Man Controller

Pac-Man controller that uses decison tree learning (ID3) to manage the states of pacman. Developed as part of the course Foundations of Game Ai at the IT-University of Copenhagen

## Features
### Decision tree learning:
ID3 algorithm builds a decision tree based on training data. The decision tree is used to contorl the gameplay states. Each states has different behaviors based on the game state. 

### State-based behavior:
Pac-Man switches between different states (e.g., Chase, Flee, Wander) depending on the game situation.

### Pathfinding:
Uses pathfinding logic to navigate the maze efficiently toward goals ( pellets, power pellets, or safe zones).
